# Learn SecByte SnakeOil Recon, JWT, Network & DeathNote CTF Labs

Hands-on cybersecurity and CTF lab collection covering SnakeOil reconnaissance, HTTP analysis, service enumeration, port sweeps, subnet discovery, target identification, VirtualBox networking, JWT security, and DeathNote hardening and breach-chain analysis.

Designed for cybersecurity students, CTF players, penetration testers, SOC analysts, and security learners practicing authorized security assessment techniques.

## Introduction

This collection combines network reconnaissance, web enumeration, application security, and defensive security exercises.

The SnakeOil labs focus on discovering hosts and services, analyzing HTTP applications, understanding JWT-related security concepts, and working through a controlled lab setup. The DeathNote exercises add defensive hardening and breach-chain analysis.

Use these resources only against intentionally vulnerable or explicitly authorized systems.

## Learning Path

A practical progression is:

1. Begin with **SnakeOil Lab Setup** to understand the training environment.
2. Use **VirtualBox Network Lab: Find the Host** to practice controlled network discovery.
3. Continue with **Signal Subnet Discovery** and **Port Sweep Secrets 2** for network reconnaissance.
4. Study **SnakeOil Target Discovery Lab** for target identification.
5. Move into **SnakeOil Recon Lab** and **SnakeOil HTTP Lab** for application reconnaissance.
6. Practice service identification with **SnakeOil Service Sleuth**.
7. Continue with **Snake-Oil Enumeration Lab** for systematic enumeration.
8. Explore **SnakeOil JWT Jam** for authentication and JWT security concepts.
9. Finish with **DeathNote Breach Chain** and **DeathNote Defense Hardening** to connect security findings with defensive controls.

## How to Use the Labs

1. Select a lab from the direct-link index.
2. Confirm that the target is an authorized training environment.
3. Read the objectives and understand the permitted scope.
4. Start with reconnaissance and information gathering.
5. Document hosts, subnets, ports, services, HTTP behavior, and application findings.
6. Use security tools only against the intended lab targets.
7. Record your methodology and evidence.
8. Review defensive mitigations and hardening practices after completing the exercises.
